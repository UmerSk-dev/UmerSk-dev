
## 📖 Project Overview

This project is my personal GitHub profile customization project. It combines a personalized SVG banner, a theme-aware profile README, and a local preview page to create a consistent developer profile.

### Features

- Automatic dark and light banner selection based on the viewer's theme.
- SVG-based banner assets.
- A local HTML preview for checking banner appearance.
- A Python script to regenerate banner assets.
- A personalized overview of my projects, technologies, and development journey.

### Built With

- Python — banner generation
- SVG — scalable banner graphics
- HTML and CSS — local preview
- Markdown — GitHub profile presentation
- Git and GitHub — version control

### Getting Started

1. Clone the repository.
2. Run the banner generation script from the project root.
3. Open `preview.html` in a browser to inspect the generated assets.
4. Update `README.md` to reflect your current projects and skills.
